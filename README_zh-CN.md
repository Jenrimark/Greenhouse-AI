## 安全与隐私

> **本地优先**：所有文件存储在你的电脑上。对话中无法通过 URL 访问你的工作台。
> 使用 Claude 时，对话结束后**记得清理**工作台中的敏感信息，以防信息在对话历史中保留。

**工作台不存储**：

- 身份证号、护照号码
- 银行账号、信用卡号
- 家庭住址（简历中的联系方式地址除外）
- 照片或任何生物识别信息
- 社保/公积金号码

**工作台可以存储**（由你控制）：

- 姓名、邮箱、电话号码
- 简历内容与求职信
- 公司名称、职位信息、薪资范围
- 面试笔记与经历记录
- 个人职业判断与分析

## 工作方式

> **核心原则**：你在 Claude 对话中协作编辑 Markdown 文件，文件本身是唯一真实来源。

### 基本流程

1. 在你的电脑上创建 `工作台/` 文件夹
2. 在 Claude 对话中，指向该文件夹（或复制粘贴文件内容）
3. 协作编辑 Markdown 文件
4. 将文件夹保存到安全位置

### 两种工作模式

| 模式 | 说明 | 数据存储 |
|------|------|----------|
| **无 MCP** | 基础工作流。Claude 读取并编辑本地 Markdown 文件。 | 仅本地文件 |
| **有 MCP** | 增强工作流。实时数据桥让 Claude 搜索 Glassdoor、公司官网和招聘页面。 | 本地文件 + 临时搜索缓存 |

### 必要技能与可选技能

技能分为两类：

**必要技能**——完成核心工作流所需：

- **greenroom**：面试状态中枢，连接所有文件
- **story-bank**：把经历加工成面试可用的故事
- **interview-script**：为每场面试定制逐字稿
- **mock-interview**：高强度模拟面试
- **debrief**：面试后复盘与回写

**可选技能**——根据求职场景按需启用：

- **job-intel**：单个岗位的情报收集（适用于重要岗位）
- **industry-brief**：行业与岗位通识速报（适用于跨行求职）

## 核心概念

### 工作台

`工作台/` 是你电脑上的一个文件夹，充当求职与面试准备的指挥中心。你可以在对话中打开它，也可以手动复制粘贴内容。没有魔法，没有隐藏字段，没有同步操作——只有你电脑上的文件。

### 技能包

技能包是 Claude 可以执行的七项特定任务。你可以在对话中调用它们（例如"运行 debrief"），也可以手动完成相同步骤。技能包仅在对话中激活，且只能操作你工作台中的文件。

### MCP 服务器

可选的本地服务器，让 Claude 搜索招聘网站、公司官网和行业信息。无需 API 密钥，完全本地运行。详细说明见 [docs/realtime-bridge.md](docs/realtime-bridge.md)。

## 技能列表

| 技能 | 用途 | 产出文件 | 优先级 |
|------|------|----------|--------|
| **greenroom** | 面试状态中枢 | 不产出文件，连接所有文件 | 必要 |
| **story-bank** | 把经历加工成面试故事 | `story-bank.md` | 必要 |
| **interview-script** | 为每场面试定制逐字稿 | `jobs/{id}/script.md` | 必要 |
| **mock-interview** | 高强度模拟面试 | `jobs/{id}/rounds/mock-{n}.md` | 必要 |
| **debrief** | 面试后复盘与回写 | `jobs/{id}/rounds/r{N}-debrief.md` | 必要 |
| **job-intel** | 单个岗位的情报收集 | `jobs/{id}/intel.md` | 可选 |
| **industry-brief** | 行业与岗位通识速报 | `library/{topic}.md` | 可选 |

每个技能的详细文档见 `skills/{name}/SKILL.md`。

## 使用方式

### 基本命令

你可以用自然语言触发技能，也可以直接使用命令：

```
greenroom              # 查看全局状态
story bank             # 更新经历库
script                 # 更新逐字稿
debrief                # 复盘最近一轮面试
mock                   # 运行模拟面试
job-intel              # 生成岗位情报
industry-brief         # 生成行业通识
```

### 典型工作流

**求职初期**：
1. 创建 `profile.md` 和 `resume.md`
2. 运行 `story bank` 建立经历库
3. 运行 `industry brief` 获取目标行业通识

**投递阶段**：
1. 创建 `jobs/{id}/job.md`
2. 运行 `job intel` 生成岗位情报
3. 运行 `script` 生成面试逐字稿

**面试阶段**：
1. 面试前：查看 `greenroom` 确认状态
2. 面试后：运行 `debrief` 复盘
3. 下轮准备：运行 `script` 更新逐字稿

### 场景：准备 AI 产品经理岗位面试

**第 1 步：建档**

```
> 我正在准备星澜科技 AI 产品经理的面试，帮我建档。
```


**第 3 步：逐字稿**

```
> 根据情报更新逐字稿，重点打磨评测体系那道题。
```

```
> 运行 mock，重点练评测体系和跨团队推动。
```

**第 5 步：复盘**

```
> 刚面完 R1，帮我运行 debrief。
```

## MCP 服务器（可选）

实时数据桥让 Claude 搜索招聘网站和公司信息，无需 API 密钥。

### 安装

```bash
# 克隆 MCP 服务器仓库
git clone https://github.com/nicobailon/mcp-remote-memory.git

# 安装依赖
cd mcp-remote-memory
npm install

# 启动服务器
npm run start
```

### 工作原理

MCP 服务器提供两个工具：

| 工具 | 功能 | 需要 URL |
|------|------|----------|
| `web_search` | 搜索并抓取网页内容 | 是 |
| `fetch_webpage` | 抓取指定 URL 内容 | 是 |

**数据流向**：

```
你的电脑 → MCP 服务器（本地） → 网页搜索 → 返回内容到对话
```

所有数据仅在对话期间临时存储于内存，对话结束即消失。

### 无 MCP 时的替代方案

如果你不想使用 MCP，可以用以下方式获取信息：

1. 手动搜索岗位信息，复制关键内容到 `library/` 文件夹
2. 在对话中直接粘贴 JD 和公司信息
3. 让 Claude 基于你提供的信息进行分析

## 贡献方式

### 贡献新技能

1. 在 `skills/` 下创建新目录
2. 编写 `SKILL.md`（遵循现有技能的文档格式）
3. 在 README 中添加技能说明
4. 提交 PR

### 贡献新行业/岗位知识

1. 在 `knowledge/` 下创建新文件
2. 包含：行业格局、岗位画像、必须能讲清的概念、高频面试话题
3. 使用 YAML frontmatter 标注元数据
4. 提交 PR

### 贡献准则

- 所有贡献采用 CC BY-NC 4.0 协议
- 保持内容实用、可操作
- 避免泛泛而谈，优先提供具体框架和案例
